# FixNote в Figma: UI-кит и все экраны

Весь дизайн FixNote одним файлом `fixnote-figma.json`. Через Figma Bridge он собирается в любом
твоём файле Figma в настоящие переменные, стили, компоненты и экраны, а не в картинки. Получатся
две страницы:

- **FixNote UI** — UI-кит:
  - переменные **FixNote Theme** (Light и Dark) и **FixNote Size** (`radius/*`, `space/*`);
  - текстовые стили `text/*` (Inter), тени `shadow/xs` и `shadow/float`;
  - иконки `icon/*` (lucide);
  - компоненты: Button (все варианты и состояния), Input, Badge, Kbd, Dialog, Note card, Note snippet,
    Sidebar и его части, Title bar, Spotlight, строки заметок; два примера окна из инстансов.
- **Screens** — все экраны приложения во всех состояниях (около 80 фреймов): первый запуск, главная,
  заметки, папки и ссылки, поиск, ассистент, диалоги, диктовка и звонок, настройки, аккаунт и Pro,
  вид «Заметки», тёмная тема, телефон. Цвета привязаны к переменным кита, текст к его стилям,
  иконки — инстансы `icon/*`, где ряды ровные — auto layout.

Повторный запуск обновляет то, что уже залито, а не дублирует.

## Что нужно

- Figma desktop с плагином **Figma Bridge (local)** (он у тебя уже стоит).
- Claude Code, Cursor или Claude Desktop с MCP `figma-bridge`.
- Для заливки из терминала: Node.js 18+ (если ставил мост через `Install.command`, он уже есть).

## Как залить

1. Распакуй архив в постоянное место, например в «Документы».
2. Открой в Figma файл, куда нужен дизайн (лучше новый или отдельный), и запусти
   **Plugins → Development → Figma Bridge (local)**. Окошко не закрывай.
3. Дальше любой из вариантов:
   - **Попроси ИИ**: открой `PROMPT.md`, скопируй промпт целиком и отправь в Claude Code или
     Cursor. Он сам всё зальёт и расскажет, что получилось.
   - **Сам, в терминале**:

     ```bash
     cd "<папка, куда распаковал>/fixnote-figma"
     node bridge/figma-bridge.mjs apply fixnote-figma.json
     ```

     Мост должен быть запущен: его поднимает MCP-клиент (открой Claude Code или Cursor). Если
     увидишь «The bridge is not running», запусти в соседнем окне терминала
     `node bridge/figma-bridge.mjs serve` и повтори.

Заливка идёт 5–15 минут (сначала кит, потом экраны по одному): в окне плагина видно, какой шаг
сейчас выполняется. Figma в это время может подтормаживать, это нормально.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| «The plugin is not running» | запусти плагин в Figma и не закрывай его окно |
| «Figma did not answer in time» | запусти ту же команду ещё раз: готовое обновится, остальное доделается |
| «Unknown job …» | в Figma старая копия плагина: закрой его окно, запусти снова, повтори |
| «Port 7331 is busy» | мост уже запущен, это нормально |
| Dark лёг отдельной коллекцией **FixNote Theme (Dark)** | так и задумано на бесплатном тарифе Figma (один режим на коллекцию) |

## Обновить мост (по желанию)

В папке `bridge/` лежит новая версия Figma Bridge (2.2.0) с командами `apply` и `export-page` и
MCP-инструментами `figma_apply` и `figma_export`. Обновить установленный мост:
`node bridge/figma-bridge.mjs install` (Claude Code и Cursor), а для Claude Desktop — двойной клик по
`bridge/Figma Bridge.mcpb`.
