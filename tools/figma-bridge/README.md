# Figma Bridge

Достаёт слои и картинки из файла, открытого у вас в Figma, — **без токена, без платного тарифа и
без лимитов**. Работает на любом плане, включая бесплатный Starter. Удобно, чтобы верстать по макету
вместе с Claude Code (или любым другим ИИ-помощником, который умеет запускать команды).

Как это устроено: маленький плагин в Figma выполняет задания через Plugin API (у него нет лимитов, в
отличие от REST API и MCP), а мост `bridge.mjs` на вашем компьютере передаёт ему задания и
сохраняет результат в файлы. Плагин ходит только на `localhost:7331` — в интернет ничего не уходит.

```
команда (вы или Claude Code) ──► bridge.mjs (localhost:7331) ◄──► плагин в Figma ──► ваш файл
                                      │
                                      └──► files/  (JSON слоёв, PNG/SVG, оригиналы фото)
```

## Что нужно

- **Figma desktop** — плагины в режиме разработки ставятся только в приложении, не в браузере.
- **Node.js 18+** — [nodejs.org](https://nodejs.org). Больше ничего: никаких `npm install`.

## Быстрый старт

1. **Поставьте плагин (один раз).** В Figma desktop откройте любой файл → меню
   **Plugins → Development → Import plugin from manifest…** → выберите `plugin/manifest.json` из этой
   папки. Плагин появится в **Plugins → Development → Figma Bridge (local)**.
2. **Запустите мост.** Двойной клик:
   - Windows — `start-bridge.cmd`;
   - macOS — `start-bridge.command` (если macOS не даёт запустить: правый клик → «Открыть», или в
     Терминале `sh start-bridge.command`).

   Откроется окно терминала — не закрывайте его, пока работаете.
3. **Запустите плагин** в нужном файле Figma: **Plugins → Development → Figma Bridge (local)**. В его
   окне должна загореться зелёная точка **Connected**. Окно можно свернуть, но не закрывать.

Готово. Файлы будут появляться в папке `files/` рядом с этим README.

## Как пользоваться

**Мышкой.** Выделите слои в Figma и нажмите **Send selection** в окне плагина — JSON слоёв и PNG 2x
каждого окажутся в `files/inbox/<время>/`.

**Командами** (во втором терминале, в этой папке):

| Команда | Что делает |
|---|---|
| `node bridge.mjs status` | запущен ли мост и подключён ли плагин |
| `node bridge.mjs info` | файл, страница и выделение, которые видит плагин |
| `node bridge.mjs tree 279:51 --depth 2` | дерево слоёв: id, тип, имя, размер, текст |
| `node bridge.mjs nodes 279:51` | полный JSON слоёв: заливки, тени, шрифты по кускам текста, автолейаут, отступы, кадрирование картинок |
| `node bridge.mjs render 279:51 --scale 2` | картинка слоя (`--format png\|jpg\|svg\|pdf`) |
| `node bridge.mjs originals 279:51` | фото в исходном виде, как их загрузили в Figma |
| `node bridge.mjs find "Hero"` | найти слои на текущей странице по имени или тексту |

- Вместо id можно вставить ссылку на слой из Figma целиком (правый клик по слою → **Copy link to
  selection**) или написать `279-51`.
- Без id команда берёт то, что сейчас выделено в Figma.
- Файлы сохраняются в `./.figma` текущей папки или в `--out <папка>`.

**С Claude Code.** Запустите мост и плагин, дальше просто пишите в чат, например: «сверстай блок
https://www.figma.com/design/…?node-id=279-51 через Figma Bridge в папке …/figma-bridge». Claude сам
вызовет `tree`, `nodes`, `render` и `originals`.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| «The bridge is not running» | не запущен мост — шаг 2 |
| «The plugin is not running» | в Figma не открыт плагин или закрыто его окно — шаг 3 |
| «Port 7331 is busy» | мост уже запущен в другом окне |
| «No layer … in this file» | в Figma открыт другой файл, а слой из этого |
| в плагине «Waiting for bridge» дольше пары секунд | проверьте, что окно моста открыто; плагин сам переподключится |

Порт `7331` прописан в `plugin/manifest.json` и в `bridge.mjs`: если меняете, то в обоих местах (и
переимпортируйте плагин).

## Безопасность

- Мост слушает только `127.0.0.1` — с других компьютеров к нему не подключиться.
- Плагину разрешён только `http://localhost:7331`, в интернет из Figma он ничего не отправляет.
- Плагин только читает файл и экспортирует картинки, ничего в макете не меняет.
