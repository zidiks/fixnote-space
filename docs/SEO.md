# SEO fixnote.space: стратегия

Состояние на 2026-10-10. Лендинг: `apps/landing` (Astro, статика, Cloudflare), en в корне, `/ru/`, `/es/`.

## 1. Где мы сейчас

**Что уже сделано хорошо**

- Статический HTML почти без JS, CSS инлайнится. Hreflang и `x-default` проставлены, у каждой страницы canonical, `trailingSlash` единый.
- Sitemap на 150 URL с i18n, robots, RSS на каждый язык, локализованные 404.
- JSON-LD: `SoftwareApplication` с Offer, `FAQPage`, `BlogPosting`, `BreadcrumbList`, `ItemList`, `HowTo`.
- Контент: 18 страниц функций и 5 сравнений (`/vs/notion` и др.), 19 статей. Всё это на трёх языках.

**Что мешает**

1. **Сайта нет в выдаче.** Поиск по домену ничего не находит. Сайт не подтверждён ни в Google Search Console, ни в Яндекс.Вебмастере, ни в Bing, так что мы не знаем, что проиндексировано.
2. **Заголовки писались без семантики.** Пример: «Спросите свои заметки», «Итоги встречи», «Навести порядок в заметках». Так не ищут. Title и H1 надо собрать из реальных запросов, например «приложение для заметок с ИИ», «расшифровка созвона», «голосовые заметки без интернета».
3. **app.fixnote.space открыт для индексации.** `/robots.txt` там отдаёт index.html (это SPA fallback), а `noindex` нет. В индекс может попасть пустая страница «FixNote» и забрать на себя бренд.
4. **Бренд «FixNote» неуникален** (fix note, fixnotes…). Брендовый трафик придёт не сразу, нужны внешние упоминания и `sameAs`.
5. **E-E-A-T.** Автор статей сейчас Organization. Человек-автор со страницей лучше и для Google, и для цитирования в AI-ответах.
6. **IndexNow нет.** Его используют Яндекс и Bing: новые и обновлённые страницы попадали бы в индекс за часы.
7. **Мелочи в схемах.** Логотип в `Organization` сейчас SVG, для Google нужен растровый ≥112px. Нет `sameAs`. Rich results по `FAQPage` и `HowTo` Google для SaaS больше не показывает: разметку оставляем, но трафика от неё не ждём.

## 2. Метрики и доступы

Решено 2026-10-11: на сайте работают **Яндекс Метрика и GA4**, но только после согласия в баннере.
- Конфиг в `apps/landing/src/data/analytics.ts`, Вебвизор выключен.
- Цели: `download` (с платформой) и `open_app`.
- Страница приватности (раздел `cookies`) обновлена на трёх языках.
- В приложении аналитики нет, и оно закрыто от индексации (`noindex`).

Плюс без скриптов:
- Search Console, Яндекс.Вебмастер, Bing Webmaster;
- PageSpeed и CrUX;
- серверная статистика Cloudflare;
- IndexNow.

Что сделать руками и куда положить ключи: [docs/seo/SETUP.md](seo/SETUP.md).

**Скачивания как конверсия.** Метрика видит только клик по «Скачать» и только у тех, кто согласился на cookie. Настоящее число скачиваний установщиков даёт GitHub (`download_count` у файлов релиза). По нему сверяем цели и считаем конверсию «органика → установка» по неделям.

## 4. Семантическое ядро

Процесс один на три языка, ядро своё для каждого (ru под Яндекс, en и es под Google):

1. **Сиды** берём из функций и болей: заметки с ИИ, приватные или зашифрованные заметки, заметки без интернета, голосовые заметки, расшифровка звонков и итоги встреч, распознавание текста с картинки, заметки из Telegram, альтернативы Notion, Obsidian, Evernote и Apple Notes, MCP и заметки в Claude или Cursor, заметка дня и повторяющиеся задачи.
2. **Расширение:**
   - ru: Wordstat (левая и правая колонки), подсказки Яндекса, запросы конкурентов из Вебмастера (когда появятся данные);
   - en/es: Bing Keyword Research, Keyword Planner (диапазоны), подсказки Google, People Also Ask, AnswerThePublic и AlsoAsked (по 3 бесплатных запроса в день);
   - на всех языках позже: GSC и Вебмастер, то есть запросы, по которым нас уже показывают.
3. **Чистка:** убираем мусор и чужие бренды без сравнительного интента, проставляем интент (информационный, коммерческий, навигационный).
4. **Кластеризация по выдаче** (скилл `seo-cluster`, SERP overlap): запросы с общей выдачей идут на одну страницу.
5. **Маппинг** кластеров на существующие URL: функция, сравнение, статья или новая страница. Дальше переписываем title, H1, description и первый абзац.

Результат храним в `docs/seo/semantics-<lang>.csv` (запрос, частота, интент, кластер, URL), чтобы следующая итерация опиралась на него.

**Гипотезы по кластерам** (проверить частотами):

| Кластер | Тип страницы | Кто сейчас закрывает |
|---|---|---|
| заметки с ИИ / AI note taking app / app de notas con IA | главная + статья «лучшие» | главная, `best-ai-note-taking-apps` |
| альтернатива Notion/Evernote/Obsidian/Apple Notes | `/vs/*` + **новые** `/alternatives/<app>/` | только `/vs/*` |
| приложение для заметок для Windows / note app for Windows | **новая** посадочная | нет |
| расшифровка созвона / meeting notes без бота | функция `call-summaries` | заголовок не по запросу |
| голосовые заметки, диктовка без интернета | `voice-notes` + статья | есть |
| текст с картинки / OCR в заметках | `text-in-images` | есть |
| зашифрованные заметки / E2EE notes | `encryption` + статья | есть |
| сохранить сообщения из Telegram | `telegram` + статья | есть, ru-приоритет |
| MCP notes / заметки в Claude, Cursor | `mcp` + статья | есть, en-приоритет, низкая конкуренция |

## 5. План

**Неделя 1: техника и подключение**

- Подтвердить GSC, Яндекс.Вебмастер и Bing, отправить sitemap. В Вебмастере выставить регион (без региона, сайт международный) и проверить, видит ли Яндекс hreflang.
- `app.fixnote.space`: настоящий `robots.txt` с `Disallow: /` и `X-Robots-Tag: noindex` (share-страница тоже, ключ всё равно в фрагменте).
- IndexNow: ключ-файл в `public/` и пинг изменённых URL в CI после деплоя лендинга.
- Схемы: PNG-логотип, `sameAs` (Telegram-бот, Microsoft Store), `operatingSystem` и `downloadUrl` у `SoftwareApplication`.
- Проверить AI Crawl Control в Cloudflare. Опционально `llms.txt`: стоит копейки, эффекта почти не даёт (Google его не использует).
- Снять baseline: `seo-drift` и PSI/CrUX по ключевым страницам.

**Недели 2–4: ядро и перетитловка**

- Собрать ядро ru, потом en, потом es (раздел 4).
- Переписать title, H1 и description у функций, сравнений и главной под кластеры. Бренд ставим в конец title, а не в начало.
- Перелинковка: функция ↔ статья ↔ сравнение по матрице из `seo-cluster`.
- Человек-автор у статей: страница автора, `Person` в `BlogPosting`.

**Месяцы 2–3: новые посадочные и внешние сигналы**

- `/alternatives/<app>/` («лучшие альтернативы Notion» и т. п.: отдельный интент от `vs`), посадочные под платформы (Windows, Mac).
- Статьи под информационные кластеры с частотой: 2–4 в месяц на язык, по брифу (`seo-content-brief`).
- Ссылки и упоминания:
  - все языки: AlternativeTo, SaaSHub, Product Hunt, листинг в Microsoft Store, каталоги MCP-серверов (Glama, mcp.so, Smithery: сильные ссылки по нише);
  - ru: Хабр, vc.ru, Telegram-каналы про продуктивность;
  - en: Reddit (r/ObsidianMD, r/productivity) без спама, только ответами по делу;
  - es: профильные блоги и YouTube-обзоры.

**Каждый месяц**

- Отчёт по GSC, Вебмастеру и Bing: запросы на позициях 5–20 с показами получают доработку страниц (самый дешёвый рост).
- `seo-drift` после каждого релиза лендинга.
- Ручная проверка, цитируют ли нас ChatGPT, Perplexity, AI Overviews и Алиса по 10–15 ключевым вопросам.

## 6. GEO (ответы нейросетей)

- Google AI Overviews и Алиса/Нейро берут источники из обычного топа. Значит, сначала классическое SEO.
- Отдельно работает:
  - пропущенные search-боты (`OAI-SearchBot`, `PerplexityBot`, `Claude-SearchBot`);
  - короткие самодостаточные ответы в начале разделов (у нас это QA-блоки);
  - сравнительные таблицы с датой проверки (уже есть в `data/apps.ts`);
  - упоминания бренда на сторонних площадках.
- Bing WMT → AI Performance показывает цитаты в Copilot. В GSC есть отчёт по AI-функциям.

## 7. KPI на 3 месяца

- Проиндексировано больше 90% URL из sitemap в Google и Яндексе.
- Небрендовые показы в GSC и Вебмастере растут каждый месяц. Цель на 3-й месяц: 100+ запросов с кликами на каждом языке.
- Скачивания установщиков и регистрации из органики (GitHub Releases и данные приложения) как итоговая метрика.
